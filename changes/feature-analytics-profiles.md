- Added Analytics Profiles (experimental, off by default): choose which account and identity attributes — including your own extended attributes — are reporting dimensions, and which combinations of them Power BI may load. Profiles are versioned, every change is kept, and identifiers, free text and attributes with more than 200 distinct values are refused with an explanation.
- Added a read-only analytics API (`/api/analytics/v1`) that returns compact, jointly aggregated counts for Power BI instead of raw rows: accounts, identities (each person counted once), the governed share of access with its numerator, denominator and exclusions, and a month-end account trend reconstructed from the audit log. Read-only API keys can refresh it.
- Every analytics result states how it was produced — profile and metric version, current or reconstructed history, months that cannot be reconstructed (never estimated), data freshness — and withholds the numbers of cells smaller than a minimum group size.
- Added a Power Query sample and a Power BI Desktop procedure for loading the datasets (not yet verified in Power BI; no template is shipped yet).
- Added the "Analytics profiles" permission for creating and changing profiles.
